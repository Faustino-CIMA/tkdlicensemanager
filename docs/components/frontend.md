# Frontend Component

## Overview

The **Frontend** is the part of the application that users see and interact with in their web browser. It is the "face" of the LTF Taekwondo License Manager.

- **Location**: `/frontend/`
- **Technology**: Next.js 16.2 (App Router) + React + TypeScript + Material Design
- **Runs in**: Docker container (based on `node:20-alpine`)

---

## What Does the Frontend Do?

Its main purpose is to provide a smooth, modern, and easy-to-use interface for different types of users:

- LTF Administrators
- Club Administrators
- Coaches
- Members

### Key Features

- User login and role-based dashboards
- License application forms
- Payment processing pages (Stripe & Payconiq)
- License Card Designer (v2.1)
- Quick Print functionality with printer profile selection
- Member profile management (including photo upload and cropping)
- Viewing license and grade history
- Administrative tools for clubs and members

---

## How It Works

1. The user opens the website in their browser.
2. The Frontend displays the appropriate dashboard based on their role.
3. When the user performs an action (e.g. submits a form, clicks "Print", or makes a payment), the Frontend sends requests to the **Backend** via REST API.
4. The Backend processes the request and returns data.
5. The Frontend updates the screen accordingly.

The Frontend never directly accesses the database — it always communicates through the Backend APIs.

---

## Technology Highlights

- **Next.js 16.2** — Modern React framework with excellent performance and SEO capabilities
- **TypeScript** — Helps catch errors early and improves code quality
- **Material Design 3** — Consistent and professional user interface
- Server-side rendering and static generation where appropriate for better speed

---

## Relationship With Other Components

- Sends requests to the **Backend**
- Displays data stored in the **Database** (via Backend)
- Shows PDFs generated by the **Backend/Worker**
- Benefits from background tasks handled by **Worker** and **Beat** (e.g. license activation)

---

## Summary

The Frontend is the user-friendly layer that makes the complex backend functionality accessible to club admins, coaches, and members. It focuses on usability, clarity, and a smooth experience while the Backend handles all the heavy lifting, rules, and data processing.
